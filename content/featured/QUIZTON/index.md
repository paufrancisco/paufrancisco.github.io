**QUIZTON** is an AI-powered web app developed as a thesis project for [St. Jude College Dasmariñas](https://sjcdc.phinma.edu.ph/). It helps educators save time and effort by automatically transforming PDF lecture materials into customized quizzes. The platform features intelligent PDF-to-question conversion using **NLP**, a centralized question bank, and flexible export options to streamline assessment creation and improve teaching efficiency.

🔒 *Repository is private due to academic confidentiality and institutional usage agreements.*
